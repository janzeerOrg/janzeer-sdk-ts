# Janzeer SDK for TypeScript

## Examples

- `01-quickstart-transfer.ts`: Basic token transfer.
- `02-subscribe-address-activity.ts`: Watch address activity.
- `03-token-create-and-transfer.ts`: Create and transfer tokens.
- `04-register-validator.ts`: Register as a validator.
- `05-vault-roundtrip.ts`: Vault operations.
- `06-watch-new-blocks.ts`: Watch new blocks via WebSocket.
