# janzeer-sdk-ts

[50 JNZ] Arabic translation of the "Sending transactions" guide

## Overview

The SDK guides exist in English only. The project is bilingual (English and Arabic), and the TypeScript SDK is the one most web developers meet first.

**What to do:** translate `docs/sending-transactions.md` (114 lines) into `docs/ar/sending-transactions.md`.

- **Modern Standard Arabic**, simple and direct. No local dialect.
- Translate the prose, headings and table text. Do **not** translate code, identifiers, command lines, file names or addresses; comments inside code blocks may be translat

## Installation

```bash
# Clone the repository
git clone https://github.com/janzeerOrg/janzeer-sdk-ts.git
cd janzeer-sdk-ts

# Install dependencies (if applicable)
pip install -r requirements.txt  # Python
# or
npm install  # Node.js
```

## Usage

```bash
# Run the project
python main.py  # Python
# or
node index.js  # Node.js
```
